**萌栖**是一个开源桌面宠物程序（MIT，可在 GitHub 提 Issue / PR）。它不只是「会动的小猫」——陪伴、提醒、专注、系统操作都收在一只桌宠里。

## 核心能力

- **多只同屏**：最多四只陪伴桌宠，各有完整动作与互动。
- **聊天气泡**：分层窗口按像素渲染的玻璃卡片，尾巴自动指向桌宠。
- **上传宠物**：单图宠物对 15 组动作都有专属表演；联网 AI 抠图去背景、AI 生成睡觉/挥爪/跳跃/吃饭姿势。
- **区域截图 & 录屏**：录屏输出真实 H.264 / MP4（有 ffmpeg 用 ffmpeg，没有回退 Windows Media Foundation），带暗化遮罩、构图线、放大镜与 3-2-1 倒数。
- **实用系统操作**：新建文件（可选后缀）、创建文件夹、删除兜底、提醒、专注。
